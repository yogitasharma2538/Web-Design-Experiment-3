
# Experiment 3: To-Do List Application

## Aim
To create a dynamic To-Do List application using JavaScript and DOM manipulation.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
1. Add new tasks.
2. Mark tasks as completed by clicking them.
3. Delete individual tasks.
4. Clear all completed tasks.
5. Edit existing tasks.
6. Search tasks.
7. Filter tasks into All, Pending and Completed.
8. Assign High, Medium or Low priority.

## Files
- index.html - Structure of the application.
- style.css - Styling and layout.
- script.js - Application functionality.

## How to Run
1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.

## Conclusion
Successfully developed a dynamic To-Do List application using HTML, CSS and JavaScript with DOM manipulation.
